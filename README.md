# 🕒 Módulo de Horario para la Facultad de Ingeniería Mecánica - Universidad Nacional de Ingeniería

Este proyecto se enfoca en la implementación de un sistema de horario para la Facultad de Ingeniería Mecánica de la Universidad Nacional de Ingeniería. Su objetivo principal es mejorar la visualización de horarios y optimizar la gestión de recursos educativos para ofrecer una experiencia educativa de calidad.

## 🚀 Tecnologías Utilizadas

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP, MySQL (XAMPP)
- **Diseño:** UML, Google Fonts, Icons Awesome
- **Herramientas:** Visual Studio Code, Adobe Acrobat, Excel

## 🌟 Funcionalidades Destacadas

- **Gestión de Horarios:** Permite a profesores, estudiantes y personal administrativo visualizar, crear y modificar horarios con facilidad.
- **Registro de Usuarios:** Autenticación segura con diferentes niveles de acceso.
- **Almacenamiento de Datos:** Utilización de bases de datos MySQL para una gestión eficiente de la información relevante.

## 📈 Objetivos

El objetivo principal de este sistema es:

- **Mejorar la Experiencia Educativa:** Facilitar la detección y resolución ágil de posibles conflictos en los horarios impresos para mejorar continuamente la experiencia educativa de los estudiantes.

## 🌐 Importancia del Sistema

Se destaca la importancia de esta herramienta como un activo fundamental para la facultad en su esfuerzo por mantenerse competitiva en un entorno educativo cada vez más digitalizado y exigente.

## 🛠️ Instalación y Uso

1. **Clonar el Repositorio:** `git clone https://github.com/tu-usuario/tu-proyecto.git`
2. **Configurar el Entorno:** Instalar XAMPP y configurar MySQL.
3. **Importar Base de Datos:** Utilizar el archivo SQL proporcionado para crear la base de datos.
4. **Ejecutar la Aplicación:** Iniciar el proyecto en el navegador web.

## 📂 Estructura del Proyecto

- `index.html`: Página principal de la aplicación.
- `css/`: Estilos CSS diseñados cuidadosamente.
- `js/`: Scripts JavaScript para una experiencia interactiva.
- `php/`: Archivos PHP para la lógica del backend.
- `uml/`: Diagramas UML detallados para el diseño del sistema.
- `fonts/`: Fuentes seleccionadas de Google Fonts para una presentación elegante.
- `icons/`: Íconos de Yicons Awesome para un toque visual distintivo.
